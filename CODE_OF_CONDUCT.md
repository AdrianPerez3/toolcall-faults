# Code of conduct

Discuss evidence and code respectfully. Welcome corrections, explain disagreements with reproducible observations, and avoid personal attacks, harassment, discrimination and disclosure of private information. Treat upstream maintainers and contributors as collaborators.

Maintainers may edit or remove disruptive content, close an unproductive discussion or restrict participation. Decisions should be proportional to the behavior and explained without exposing private reports.

For conduct concerns, ask the maintainer for a private contact route without posting identifying or sensitive details. Security reports use [SECURITY.md](SECURITY.md). This policy covers this project's repositories and discussions; it does not claim authority over other communities.
